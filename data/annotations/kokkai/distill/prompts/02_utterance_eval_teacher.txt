## 採点基準

### 主評価軸 (0-3点)
1. issue_clarification (論点整理): 議論のズレを戻したり、今考えるべき論点を明確にした度合い
   - 0: 寄与なし / 1: 少し整理しているが曖昧 / 2: 論点を明確にし議論しやすくした / 3: 議論の混線を解消し方向を明確に変えた
2. decision_progress (意思決定寄与): 選択肢比較、判断材料提示、結論への前進にどれだけ効いたか
   - 0: 寄与なし / 1: 判断の補助にはなる / 2: 選択肢比較や条件整理に役立った / 3: 実質的に決定を前に進めた・決定打になった
3. risk_detection (リスク検知): 抜け漏れ、依存関係、障害要因を見つけた度合い
   - 0: リスク指摘ではない / 1: 軽い懸念 / 2: 具体的なリスクを明示 / 3: 重要な見落としを発見し方針修正に影響した
4. actionability (アクション化): 議論を次の具体行動に落とし込んだ度合い
   - 0: 行動につながっていない / 1: 抽象的な次ステップ / 2: 誰が何をするかがある程度明確 / 3: 担当・期限・内容が具体的で実行可能

### 補助評価軸 (0-3点)
5. groundedness (根拠性): 事実、データ、具体例に基づいているか
   - 0: 根拠なし / 1: 軽い具体性 / 2: データ・事例・経験則が明示 / 3: 強い根拠で議論を支えている
6. novelty (新規性/洞察): 既出でない重要視点や本質的な指摘を含むか
   - 0: 新規性なし / 1: やや新しい視点 / 2: 明確に新しい有益な視点 / 3: 議論の質を変えるレベルの洞察
7. summarization (要約・交通整理): 合意点、未決事項、議論の流れを整理したか
   - 0: 該当なし / 1: 軽いまとめ / 2: 状況整理として有用 / 3: 会議の理解を大きく助けた

### 減点軸 (0〜-3点)
8. duplication (重複): すでに出た内容を追加価値なく繰り返し
   - 0: 重複なし / -1: やや重複 / -2: ほぼ言い換えのみ / -3: 無価値な繰り返し
9. verbosity (冗長): 結論までが長く情報密度が低い
   - 0: 簡潔 / -1: やや長い / -2: 長くて要点が薄い / -3: かなり冗長で流れを悪化
10. off_topic (論点逸脱): 会議目的や現在の議題から外れている
    - 0: 逸脱なし / -1: 少し逸れる / -2: 明確に脱線 / -3: 進行をかなり妨げる脱線
11. unsupported_assertion (根拠薄い断言): 根拠不明なのに強く言い切っている
    - 0: 問題なし / -1: やや危うい / -2: 根拠不足が目立つ / -3: 誤誘導リスクが高い
12. override (上書き発言): 直前の他者発言を無視し、応答せずに自説を被せている
    - 0: 問題なし / -1: 直前発言への応答が薄い / -2: 直前の論点を明確に遮っている / -3: 議論の流れを大きく阻害

## 重要な判定原則
- 短くても会議を動かした発言は高評価
- 長くても新規性や進展がなければ高評価しない
- 既出内容の言い換えは重複として減点
- 発言後に議論が収束した・決定事項が固まった・次アクションが決まった場合は貢献度を高めに評価
- 議論の整理、決定前進、リスク発見、行動化を重視する
- 肩書きや立場で補正しない
- 直前の他者発言を無視して自説を被せた場合は override として減点する。ただし、直前発言を引用・要約・訂正して論点を修正している場合は減点しない
- 迷ったら甘くしすぎない

## 国会会議録に対する追加指針（蒸留用）
- 「○○委員長 これより会議を開きます」「異議なし」「挙手多数。よって、そのように決定いたしました」等の
  純粋な議事進行・採決宣言は decision_progress を高くしすぎない。会議を「動かした」のは進行係の定型句ではなく、
  論点を提示した討論・質疑・趣旨説明である点に注意する。
- 反対討論・賛成討論・質疑は、論拠（データ・前例・割合・経緯）を伴うほど groundedness と
  decision_progress を高く評価する。根拠が薄い断言は unsupported_assertion で減点する。
- 趣旨説明・事務総長の議事順序説明は情報共有として扱い、論点を明確化していれば issue_clarification を加点する。
- 出席者名簿・資料の貼り付け・「会議録情報」など、発話とは言えない塊は評価対象にしない
  （蒸留データから除外される前提だが、万一渡された場合は全軸0・speech_type は「雑談/脱線」とする）。
