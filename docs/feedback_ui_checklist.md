# フィードバック UI 手動チェックリスト (Issue #79)

D-1 (Top5 並べ替え) / D-2 (発言カード👎) の手動 E2E 確認手順。バックエンド #78 の
フィードバック API が必要。

## 事前準備

```bash
# バックエンド (フィードバック API)
cd backend && uv run uvicorn app.api.main:app --reload   # http://localhost:8000

# フロントエンド (別ターミナル)
cd frontend && npm run dev                                # http://localhost:5173
```

- 任意のサンプル会議を分析し、結果画面（会議サマリー）を表示しておく。
- `org_id` は暫定で `localStorage` の `meeting_score_org_id`（既定 `org_local`）を
  `X-Org-Id` ヘッダで送る。別組織を試す場合は DevTools で値を変更する。

## D-1 Top5 並べ替え（会議サマリー）

- [ ] 「前進した発言」パネル見出し横に **「Top5 を直す」** ボタンがある
- [ ] クリックでモーダルが開き、Top5 が一覧表示される
- [ ] 行をドラッグして並べ替えできる（マウス）
- [ ] ドラッグハンドルを Tab でフォーカス → Space/矢印キーで並べ替えできる（キーボード）
- [ ] 「外す」で行を除外できる
- [ ] 「＋ 他の発言から差し替え」→ 検索 → 候補クリックで追加できる
- [ ] メンバーを入れ替えて「保存」→ トースト「ありがとうございました（N 件の比較に反映）」
- [ ] **サーバ確認**: `POST /api/feedback/topk` が呼ばれ、`generated_pairs > 0`
      （= `feedback_pairwise` に `source='top5_reorder'` で複数行 INSERT されている）
- [ ] 「キャンセル」/ ✕ / 背景クリックで保存せず閉じる
- [ ] 並べ替えていない（変更なし）状態では「保存」が無効

> サーバ側の自動ペアワイズ展開は backend 統合テストでも担保:
> `backend/tests/test_feedback_api.py::test_post_topk_expands_to_pairwise`

## D-2 発言カード👎（タイムライン）

- [ ] 発言カードを選択すると、右上に控えめな ⚑ アイコンが現れる（未選択時は出ない）
- [ ] クリックで popover が開く
- [ ] 「過大評価 ↓ / 過小評価 ↑」が必須トグル（未選択だと「送信」無効）
- [ ] 軸チェックボックス（採点 7 + 減点 4 = 11 個）を複数選択できる（任意）
- [ ] コメントは 80 字まで（任意）
- [ ] 「送信」→ `POST /api/feedback/axis_flag` → トースト「ありがとうございました」
- [ ] popover 内のクリックでカード選択が誤作動しない（伝播停止）
- [ ] 「キャンセル」で閉じて状態リセット

## フィードバック状況（任意・薄い表示）

- [ ] サマリー下部に「貴社のフィードバック: 比較 N 件／段階 X（…）／次の段階まで M 件」
- [ ] バックエンド未起動時は何も表示されない（エラーで画面が壊れない）

## 「人物ランキング」を想起させない（原則レビュー）

- [ ] バッジ・トロフィー・星・順位の優劣を煽る色使いが無い
- [ ] Top5 は「**発言**を前進度で並べる」ものであり、人物の優劣表示ではない
- [ ] 段階表示は淡々とした事実（番号＋状態文）のみで、ゲーミフィケーション要素が無い
- [ ] 👎 は常時表示でなく選択時のみ＝「批評ツール」化していない

## アクセシビリティ

- [ ] すべての操作ボタンに `aria-label`
- [ ] モーダルは `role="dialog"` `aria-modal`、popover は `role="dialog"`
- [ ] 方向トグルは `role="radiogroup"`/`radio`、Top5 並べ替えはキーボードで完結
