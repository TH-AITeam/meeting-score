# #9 [feature] 上書き発言 / マウント検出

**Labels**: `enhancement`, `P2`
**Milestone**: v0.3

## 概要

直前の他者発言を無視して被せる「上書き発言」を検出する。AGENT.md §2 の「肩書きで補正しない」を守るための安全装置。

## 判定材料

- 直前発言と話者が違う
- 直前発言の論点に答えていない（embedding 類似度 < 閾値、または LLM 判定）
- 自分の主張を新たに提示している（speech_type が 提案 or 意思決定促進）

## やること

- [ ] `app/scoring/rule_corrections.py` に `_check_override(target, prior)` を追加
- [ ] `Penalties` に `override: int = Field(0, ge=-3, le=0)` を追加
- [ ] プロンプトにも「直前の他者発言を無視して自説を被せた場合は減点」を追記
- [ ] サンプル会議に「上書き発言」の検査ポイントを仕込む

## 完了条件

- 検査用に作った「上書き発言」のペナルティが必ず -1 以下になる
- 正当な「論点修正」(直前を引用して訂正する) は減点されない

## 注意

過検出するとブレストや活発な議論を全部減点する事故になる。**閾値は緩めスタート**で eval で調整。
