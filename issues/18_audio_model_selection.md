# #18 [decision] 音声処理モデル選定(ASR + 話者分離)

**Labels**: `decision`, `model`, `P1`
**Milestone**: v0.4

## 概要

音声入力パイプライン(#10)で使う **ASR モデル**と **話者分離モデル**を比較選定する。

## 比較カテゴリ

### A) ASR (音声→テキスト)

OSS/商用問わず、日本語性能と word-level timestamp 取得可能なものを 2〜4 候補。

候補抽出条件:
- 日本語精度(CER/WER)が現実的
- word-level timestamp が取れる
- A100 1枚で1時間音声を 10分以内に処理できる
- 商用利用可

### B) 話者分離 (Diarization)

候補抽出条件:
- 2〜6 人の会議想定
- 話者数自動検出 or 指定可能
- ASR の word-ts と突き合わせられる出力形式
- 商用利用可

## 評価軸

| カテゴリ | 軸 | 計測方法 |
|---|---|---|
| ASR | CER (文字誤り率) | 自前録音3本(15分以上)+ 公開コーパスで測定 |
| ASR | RTF (real-time factor) | A100 でwall-clock計測 |
| ASR | 固有名詞耐性 | 会議特有用語(プロダクト名/人名)の認識率 |
| Diar | DER (Diarization Error Rate) | 同上 |
| Diar | オーバーラップ発話処理 | 被せ発話を分割できるか |
| 統合 | 結合後の発言分割精度 | 「正しい発言単位に区切れた率」を人手評価 |

## やること

- [ ] 候補リストを `docs/audio_model_candidates.md` にまとめる
- [ ] 評価用音声を `data/eval_audio/` に最低3本配置(会議形式、2〜4人、各15分以上)
  - **プライバシー配慮**: 自分で録音 or 合成音声を使う、本物の会議は使わない
  - 参照(正解)文字起こしを手で作る
  - 参照話者ラベルを手で作る
- [ ] ASR 候補それぞれで CER / RTF / 固有名詞認識率を計測
- [ ] Diarization 候補それぞれで DER を計測
- [ ] ASR × Diarization の組み合わせで結合後品質を比較
- [ ] 結果を `docs/audio_model_selection_v1.md` にまとめる
- [ ] 第一採用を決定

## 注意

- 会議の音質は録音環境で激変する。**評価音声と本番音声の品質ギャップ**を意識
- 候補に HF Hub 配布のモデルが含まれる場合、トークンやライセンス要件を必ず確認する
- 国産日本語特化モデルもライセンスと配布形式を必ず確認
- 多言語(日英混在)の会議も想定するなら追加軸を立てる
