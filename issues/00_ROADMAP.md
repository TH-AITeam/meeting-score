# Roadmap

## 方針

- **OpenAI 依存を捨てて、判断モデルをローカル LLM に置き換える**
- **音声入力(ASR + 話者分離)を正式パイプラインに昇格**
- **学習データを構造化(Tier1〜3)して、SFT/DPO/重み回帰の3本柱で AI 開発する**
- **eval ハーネスを先に整備**して、改善を数値で語れる状態にする
- **特定モデルへの依存は避ける**。判断 LLM / 音声処理モデルは別 Issue (#17, #18) で比較・選定してから採用

「動く MVP」から「学習可能なシステム」へ。

```
   ↓

   ↓

   ↓
#17 (judgment model selection) ─→ #11 (local backend) ─→ #16 (migration)
   ↓
#12 (SFT data) ─→ #13 (SFT) ─→ #14 (DPO)

                  #15 (weight regression)
```

## 重要な原則

- **モデルは比較してから決める**。 #17 / #18 を後段の実装より前に通すこと
- **eval ハーネス(#4)が先**。 これがないとモデル選定もチューニングも数値で語れない
- **アノテ済みデータ(#5)が比較の基準**。 これがないと #17 #18 が主観評価になる
